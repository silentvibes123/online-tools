Tips for Merging PDFs for Government Job Applications

If you are applying for SSC CGL, UPSC, Railway NTPC, or any state government job, here are important things to keep in mind:

  • Check the file size limit — most portals accept PDFs under 2MB or 5MB. Compress images before converting to PDF.
  • Order matters — usually the sequence is: application form → photo ID → marksheets → certificates → caste certificate (if applicable)
  • Use PDF/A format if the portal specifically asks for it
  • Scan at 150-200 DPI — higher DPI increases file size unnecessarily
  • Black and white scans are smaller in size than color scans for text documents
Common Mistake: Many students merge PDFs but forget to check the total file size. Always verify the final merged PDF size before uploading to the exam portal.

File Naming Before You Merge

Rename your files with numbered prefixes before merging — this keeps documents in correct order when you select them all at once:

  • 01_Application_Form.pdf
  • 02_Aadhaar_Card.pdf
  • 03_10th_Marksheet.pdf
  • 04_Graduation_Certificate.pdf
  • 05_Category_Certificate.pdf

On Windows: Right-click file → Rename. On Android: Long-press file in Files app → Rename.

What to Do If the Merged PDF Is Rejected

Rejection reason: File too large
Compress images to 20–50KB before converting to PDF. Use our Exam Photo Resizer for photos. Scan documents at 150 DPI grayscale instead of 300 DPI color.
Rejection reason: Invalid format or corrupted
Open the merged PDF in Chrome → Print → Save as PDF. This re-exports as a standard-format PDF that most portals accept.
Rejection reason: Password-protected page detected
One of your source PDFs has a password. Remove it first: open in Chrome → enter password → Print → Save as PDF → use this new copy for merging.
