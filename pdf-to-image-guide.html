Common Problems & Fixes

Extraction is slow or browser freezes
Large PDFs (above 50 pages or 20MB) can be heavy on browser memory. Try processing a smaller PDF first. On mobile, use Chrome for best performance.
Images look blurry
This happens with scanned PDFs where the original scanned pages are low resolution. The tool cannot improve the source quality. Try zooming in on the downloaded image to check actual quality.
PDF is password-protected
Open the PDF in Chrome → enter the password → print → Save as PDF. This creates a clean, unprotected PDF that you can then convert to images.

Is My PDF Uploaded Anywhere?

No. The entire conversion runs in your browser using PDF.js — Mozilla's open-source PDF rendering library. Your file is never sent to any server. All processing is local to your device.
